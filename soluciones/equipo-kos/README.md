# Read Me  

## Proposito  

Este proyecto analiza cómo las celebraciones (días festivos) impactan en el comportamiento de los viajes aéreos, tanto nacionales como internacionales, en distintos países entre los años 2010 y 2019.  
La aplicación fue desarrollada en Streamlit e incluye:  
KPIs y análisis: métricas clave antes, durante y después de los meses de mayor número de celebraciones.  
Simulador: estimaciones de pasajeros nacionales e internacionales por país y mes.  
Relato visual: gráficos explicativos y recomendaciones sectoriales.  

## Estructura de archivos

Dentro de la carpeta soluciones/equipo-kos/ se encuentran:  
streamlit_app.py → aplicación principal en Streamlit.  
requirements.txt → dependencias necesarias para ejecutar la app.  
countries.csv → catálogo de países.  
global_holidays.csv → dataset de feriados y festividades globales.  
monthly_passengers.csv → dataset de pasajeros mensuales (domésticos e internacionales).  
Kos_datarush.mp4 → video de la solución.  
README.md → este documento.  

## Requisitos previos  

Tener Python 3.9+ instalado.  
Instalar dependencias desde requirements.txt  

## Resultados esperados

Visualizar cómo los feriados impactan en el volumen de pasajeros.  
Simular escenarios para distintos países y meses.  
Generar recomendaciones estratégicas para sectores como aerolíneas, turismo, hospedaje, retail y transporte terrestre.
